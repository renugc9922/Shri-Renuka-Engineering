# Shri Renuka Engineering Works — Company Website

> A modern, responsive corporate website developed for **Shri Renuka Engineering Works (SREW)**, a mechanical engineering and CNC machining company based in Solapur, Maharashtra.

**Live Website:** https://shri-renuka-engineering.vercel.app/

---

## About

This website provides Shri Renuka Engineering Works with a professional digital presence to showcase its **engineering services, manufacturing capabilities, infrastructure, achievements, leadership, career opportunities, and contact information**.

The website is designed with a clean industrial aesthetic and focuses on responsiveness, accessibility, usability, and smooth interactions across devices.

---

## ✨ Features

* **Responsive Design** — Optimized for desktop, tablet, and mobile
* **Modern UI/UX** — Clean corporate design with interactive components
* **Responsive Navigation** — Sticky navbar with mobile menu
* **Smooth Scrolling** — Seamless navigation between sections
* **Scroll Animations** — Subtle reveal animations for better visual experience
* **Service Showcase** — CNC machining, grinding, SPM, and shaft manufacturing
* **Company Overview** — History, capabilities, infrastructure, and achievements
* **Careers Section** — Job and internship application form
* **Contact Section** — Email, phone, address, and map integration
* **Accessibility** — Semantic HTML and keyboard-friendly navigation
* **Performance Focused** — Lightweight static website with minimal dependencies

## 🚀 Getting Started

### Prerequisites

* Modern web browser
* VS Code or any preferred code editor
* Git *(optional)*

### Clone the Repository

```bash
git clone <repository-url>
cd shri-renuka-website
```

### Run Locally

This is a static website, so no backend or database setup is required.

Simply open `index.html` in your browser.

For development, **VS Code Live Server** can be used for automatic browser refresh during changes.
